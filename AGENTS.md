# Рабочие инструкции приложения

Актуальное состояние: `docs/PROJECT_STATE.md`; правила работы: `docs/OPERATING_MODEL.md`; автономная очередь: `docs/AUTONOMOUS_WORK.md`.

## Экономия токенов — правило пользователя от 02.10.2026

- Выбирать минимальную достаточную глубину разбора: низкую для известных повторяющихся действий, среднюю для обычных правок, высокую для архитектуры, неясных ошибок и проверки достоверности данных.
- После сложного решения возвращаться к короткой обработке исполнения. Повышать глубину при новой неопределённости или сбое проверки.
- Читать нужные фрагменты, повторно использовать проверенные материалы и инструменты, объединять однотипные операции. Не повторять общий поиск и уже пройденные проверки без новой причины.
- Проверять последствия изменения по его масштабу. Сохранять обязательные проверки фактов, личных данных, восстановления и публикации.
- Сообщать коротко о результате этапа. Полный архив создавать после существенного этапа.
- Пользователь разрешает автоматически выбирать доступную модель/уровень рассуждения под задачу, если среда предоставляет такой инструмент. Не объявлять реальное переключение без его выполнения; при отсутствии инструмента применять правило к объёму анализа и операций. Не менять глобальные настройки и расписание работы ради этой инструкции.
- Не привлекать дополнительных агентов без отдельного разрешения на делегирование.
