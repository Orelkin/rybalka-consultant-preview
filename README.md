# Рыбалка — консультант · Preview

Публичная безопасная preview-сборка проекта.

## Канонические управляющие документы
- [PROJECT_STATE](docs/PROJECT_STATE.md) — текущее состояние проекта.
- [ROADMAP](docs/ROADMAP.md) — приоритеты и очередь задач.
- [WORK_LOG](docs/WORK_LOG.md) — интегрированная история работ.
- [SOURCES_OF_TRUTH](docs/SOURCES_OF_TRUTH.md) — что считать актуальным при конфликте версий.
- [OPERATING_MODEL](docs/OPERATING_MODEL.md) — роли чатов, Work и фоновых процессов.

## Важно
- Канонический каталог: 63 вида, 6 групп.
- Старые handoff/сборки на 110/111 видов — архив.
- Stage 2 сохраняется как визуальный эталон; текущая разработка не должна самовольно менять согласованный дизайн.
- Публичный preview не должен содержать точные приватные координаты пользователя.
