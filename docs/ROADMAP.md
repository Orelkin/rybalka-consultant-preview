### P4 — «Куда ехать»
Цель: объяснимая рекомендация вместо процента клёва.

Входы:
место старта + дата/время + целевой вид + доступ/транспорт + погода + температура воды + Δ уровня 24/72 ч + течение + свет + кислород при наличии + сезон + кормовая база + правила + личный опыт.

Выход:
место → структура → горизонт → метод → подача → запасной сценарий → объяснение → уверенность.
